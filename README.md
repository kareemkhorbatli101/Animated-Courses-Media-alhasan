# Recordings - Al-Hasan International, Student Book 1

The spoken audio for the ten units at
<https://learnactively.com/alhasan/book1/>. Synthesised offline by Piper
through `tools/ah_site.py --audio` in the course pipeline and published
here by `tools/ah_media.py`. Nothing here is edited by hand.

It lives apart from the site so that the site's repository carries only
text. The course pages fetch these files from this repository's own
GitHub Pages site. Each file is named by a hash of the words and the
voice that make it, so a URL can never come to mean a different
recording, and a line shared by two units is stored once.

Every file is a byte-for-byte copy of a cached clip in the pipeline, so
the pipeline's cache - not this repository - is the authority on what the
course says, and this repository can be rebuilt from it.
